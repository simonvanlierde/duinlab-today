# duinlab-today 0.2.0

duinlab-today is a daily morning paper for The Hague: pictures, sourced reading, a short quiz,
daily games and useful local information in one page.

- Run the paper for your own city: one TOML file sets the place, time zone, units, pictures and
  games, with Utrecht and Evanston as examples.
- See rain coming in 5-minute steps for the next two hours, from KNMI's radar nowcast.
- Find moonrise and moonset in the almanac, and open each picture's original from the viewer.
- Reach the games sooner on a phone: they now follow the picture, facts, word and quiz.

Read it at [today.duinlab.nl](https://today.duinlab.nl/).
The [changelog](../../CHANGELOG.md) lists the release's changes, and the
[privacy statement](../privacy.md) says what the page keeps.
